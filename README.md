# Futsal Manager 2027

Jogo de gestão de futsal, inspirado no Football Manager.

## Estado atual: Etapa 1 (estrutura)
- Menu principal, novo jogo, ecrã do clube com navegação por secções
- Avançar no calendário
- Gravar em 3 espaços, carregar, apagar
- Exportar e importar jogos em ficheiro

## Como abrir
No StackBlitz: `stackblitz.com/github/O_TEU_UTILIZADOR/futsal-manager-2027`

## Estrutura
- `src/core` lógica do jogo (estado, gravações, tipos)
- `src/ui` ecrãs e navegação
